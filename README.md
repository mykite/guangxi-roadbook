# 南行手记 · 广西自驾路书

长沙出发，一个人、一辆增程车，慢慢看广西。

**在线访问：https://mykite.github.io/guangxi-roadbook/**

## 功能

- 高速优先30天 / 不走高速42天，完整逐日行程。
- 每天的上午、下午、驾驶估算、补能夜宿和雨天替代。
- 选择出发日期，自动换算每日日期与预计返程日期。
- 计划酒店日标记、逐日打卡、进度统计。
- 出发日期、路线选择和进度保存在当前浏览器；不上传服务器，不跨设备同步。
- 手机和桌面布局、随系统切换浅色/深色，无外部脚本依赖。

## 阅读攻略

- [完整逐日文字版](guide/daily-plan.md)
- [总体路线、预算与用车建议](guide/overview.md)

行程资料整理于**2026年11月5日**。天气说明不是实时预报；出发前复核县级24—72小时预报、道路管制和景区通知。停车区域为车宿候选，是否允许过夜、厕所开放和充电可用性须当天核实。增程车露营行为以车辆当前版本说明书为准。

## 本地预览

仓库根目录运行：

```sh
python3 -m http.server 8000
```

然后打开 `http://localhost:8000/`。

## 修改与构建

`src/roadbook.html` 包含页面内容、样式、交互以及72天的内嵌数据；`src/shell.html` 提供独立网页外壳和浏览器本地存储。

修改后执行：

```sh
python3 scripts/build.py
```

提交生成的 `index.html`。GitHub Pages从`main`分支根目录发布；不需要安装依赖或配置服务器。

金额、里程和驾驶时间是规划估算，完整环线含返回长沙；中途因天气休整时后续日期顺延。
