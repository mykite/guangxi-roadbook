# 长沙出发，广西增程车慢游攻略

已补充独立的[逐日执行版](daily-plan.md)：高速30天和国道42天均已逐日列出上午、下午、驾驶、补能夜宿和雨天调整。具体每日安排以逐日版为准；本文保留总体路线、预算与用车参考。

版本日期：2026年11月5日，北京时间。一个人，按用户补充暂定为2022款深蓝SL03增程版，把“能跑160公里”理解为纯电实际续航；出发日、车机版本和预算未定。以车宿为主，每4—6晚安排一次酒店，天气不适合时增加住店。

里程与车时均为规划区间，未接入高德/百度实时算路，不是逐段导航实测；车时不含充电、吃饭、游览及堵车。国省道路段以当天导航、路牌和管制为准。充电站余位、停车过夜许可、厕所开放、景区票价均需临行核实。

## 先看选择

| 项目 | 高速优先版 | 不走高速版 |
|---|---|---|
| 节奏 | 约30天，可缩到24—26天或延长 | 约42天，可按天气增减 |
| 全程参考 | 约3500—4100公里，含往返长沙和适量景区绕行 | 约3900—4600公里，含往返长沙和适量景区绕行 |
| 驾驶安排 | 主要转场2—4小时，首日稍长 | 多数移动日100—180公里，少数长段要拆开 |
| 补能 | 高速用合适混动模式，城市和游览时充电 | 尽量在吃饭、散步、住店时充电，燃油兜底 |
| 一人现金预算 | 30天约5500—8900元 | 42天约4800—8300元 |

预算包含餐饮、油电、通行、少量门票、停车与偶尔住店；不含买装备、车辆折旧、固定保险、保养维修。另留1500—2000元应急。两版不是相同天数比较：国省道省路费，但多出来的十余天也有生活费。

基本环线：长沙→永州→桂林→兴坪/阳朔→柳州→南宁→北海→钦州/防城港→东兴→崇左→明仕田园→德天→靖西→百色→巴马→河池/宜州→柳州→桂林→永州→长沙。

北海位于钦州以东，走完北海再向西去防城港，会有一段合理回折；这比为了完全不走回头路，额外拉去玉林、梧州更适合控制里程。

## 当前日期和天气怎么影响路线

截至11月5日查到：广西11月上旬受接连冷空气影响，4—6日桂北有降雨，8—9日还有一轮降温降雨；北部湾7—9日海上风力增大。11月4日发布的进一步预报提示，8—9日北部湾海面可能出现7—8级、阵风9—10级东北风。近期不把海边车宿、坐船和山顶日出写成刚性任务。

- 如果11月6日前后出发：先去永州，再到桂林；11月8—9日前后优先安排桂林或柳州的城市休整，避免追着冷空气去海边。具体是否转场，看当天预警和路况。
- 如果暂时不用马上走：先看11月9日以后是否出现连续2—3天相对稳定的天气窗口，再决定出发；这里不把9日当成必然放晴日。
- 龙脊梯田三大核心梯田区已于11月1日开镰收割，近期不再作为金黄稻田必去点；若只为寨子和梯田线条、又恰好遇到好天气，可以另加2天。
- 30天/42天表内的D1、D2是顺序，不是未来逐日天气承诺。如果11月6日出发，30天版约到12月5日，42天版约到12月17日，返湘前需重新关注降温、雾和山区道路情况。

每天早上查目的地未来24—72小时；下午查过夜点所在县和下一段山路；天气恶化时就近停县城。7天以后只做趋势参考，长行程靠滚动调整。

## A：高速优先，30天参考行程

原则是长距离转场走高速，山水景区之间走正常开放的地方道路。高速并不意味所有景区门口都能高速直达。

长沙—桂林可参考衡阳方向接G72泉南高速；桂林—阳朔常用G65方向；柳州—南宁常用G72方向；南宁—北海常用G75方向，具体入口和连接线让实时导航选择。

检索到的G72永州—桂林施工旧公告，计划时间是10月12—19日，并写有特殊天气可能后延。不能据此说11月5日仍封闭，也不能凭旧公告确认已恢复；出发当日查导航和交警最新通告。[原公告](https://news.guilinlife.com/article/5leb1a47656cca4e138a.html)

## B：不走高速，42天参考行程

导航选择“不走高速”；若也不接受普通收费路段，再选择“避免收费”，两者不完全相同。每次只设当日目的地和必要途经点，不用全广西的大串导航，以免系统为了缩短距离带进乡道。

湖南进广西：长沙→湘潭→衡山→衡阳，主要参考G107走廊；衡阳→祁东→祁阳→永州零陵→东安→全州→兴安→桂林，主要参考G322走廊。先把湖南沿途也当作旅行，没必要第一天国道硬开到桂林。

## 重点地方到底怎么玩

**桂林/阳朔：4—6天。** 桂林以东西巷和两江四湖周边慢逛为主；兴坪安排半天至一天，在开放岸边看漓江，不把车开进江滩。阳朔把旧县、遇龙桥、工农桥分开走，车停正规停车场后步行或租自行车。遇龙河与漓江水上项目择一即可；出发前查运营、水位和限制。十里画廊部分路段可能管制，别默认私家车随时可进入。下雨不去湿滑山顶，不把江边坝面当步道。

**柳州：2—3天。** 一天龙潭公园、柳侯公园；一天博物馆、柳江夜景。螺蛳粉、卷粉、小吃按当地普通店吃，不必为网红店长时间排队。柳州博物馆官网标示免费开放，实际开放及预约看馆方通知：[柳州博物馆](https://www.lzbwg.org.cn/home/index/index.html)。

**南宁：2—3天。** 作为休整城市，广西民族博物馆、邕江岸边、老城区任选；青秀山作为有体力和天气窗口时的付费选择。白天充电与采购，住店洗衣烘干。

**北海/防城港/东兴：5—7天。** 北海老街、银滩、侨港分别慢逛，不安排一天跑三处日落。防城港以西湾、开放海滨步道为主；东兴看口岸城市生活。海鲜先问总价、计价单位和加工费；一个人用小份菜更容易控预算。涠洲岛另做独立的2—3天加项，需核对船班、停航和留车安排，本攻略基本预算不含上岛。

**明仕/德天：2—3天。** 明仕的田园步行和开放公共道路已能提供不错体验，竹筏自愿选择；德天留半天至一天。德天日场含观光车成人票目前可见报价约115元，预算按120—150元预留，竹筏、魔毯等另算，购买时再核实。[售票参考](https://touch.piao.qunar.com/touch/detail.htm?id=11447)。明仕到德天的公路转场约60公里，可用作当天行程尺度参考：[文旅部路线资料](https://zhuanti.mct.gov.cn/csxz2022/guangxi/detail/1523.html)。

**靖西：3—5天。** 一天鹅泉与旧州，一天渠洋湖，一天休息或选择一个峡谷项目；大雨、连续降雨或景区预警时取消峡谷和漂流。不要把所有收费点都买一遍。文旅部资料给出的尺度：鹅泉到旧州约6公里，鹅泉到渠洋湖约35公里，适合以城区为基地分开游览：[靖西山水田园线路](https://zhuanti.mct.gov.cn/rxhmxjgn2022/beijing/detail_g7yU_506/3463.html)。

**巴马/河池：3—5天。** 巴马以盘阳河沿线与村镇慢生活为主；不感兴趣可以只停一晚。三门海等洞穴/游船另加一天并查开放情况。河池、宜州承担休息补给功能，不要求每到一城都买景区票。

建议把门票预算集中在“德天+自己真正想看的1—2个收费项目”。景区当前是否开放、优惠、船班和票价，均以购买前的官方通知为准，不预售捆绑整趟行程。

## 增程车160公里，具体怎么补能

不把160公里当作高速、冷天、开暖风时都能达到的距离，也不把充电站铺成必须逐个打卡的任务。你有燃油兜底，重点是保证夜间车宿用电。

1. 普通公路尽量把充电和午饭、散步合并。以80—100公里作为查看补能机会的节奏，不是“每100公里必须充”。每站看接口、功率、开放时间、停车费和最近成功充电记录；提前存一个附近备用站。
2. 高速用车辆允许的合适混动/保电策略，保留晚间电量。深蓝负责人对SL03早期版本的介绍包含市区、高速、山地三种能量管理模式，保电目标不同；但实际按钮、逻辑和阈值以你车上的当前版本为准，不把行驶保电模式当作睡眠安全设置。到城市后再充，不必为了坚持纯电在每个服务区停一次；如果本来就要吃饭休息、同向服务区空闲，顺便充更合适。[厂家负责人原始说明](https://www.xchuxing.com/ins/132228)
3. 加油按厂家指定标号；山区、沿边路线出发前至少保留半箱左右燃油更从容，不等低油报警才找站。加油与充电不能互相替代故障救援，出发前检查车况。
4. 最后一次主要补能放在县城。去明仕/硕龙前在崇左或大新查桩；去鹅泉/渠洋湖前在靖西；巴马—东兰—金城江按每个县城查看补能。热门景点的桩不能作为唯一依赖。
5. 过夜前建议把电补到约70%—90%，具体服从车型手册和充电上限。先测试一晚空调耗电，再倒推需要多少电量；160公里纯电续航对应的电池未必大，暖风消耗占比可能明显。次晨还要留出到下一补能点的电量。

重点补能城市顺序：长沙→衡阳/祁阳→永州→全州/兴安→桂林→阳朔→柳州→南宁→钦州/合浦/北海→防城港/东兴→上思（国道版）→崇左/大新→靖西→百色→巴马→东兰→金城江/宜州→柳州→桂林→永州。

广西已有高速服务区充电设施覆盖和较大公共充电网络，但“有桩”不等于抵达时一定空闲、正常或适配。这里给的是补能城市和选择规则，没有冒充查询到实时可用枪位。[广西充电网络报道](https://www.gx.xinhuanet.com.cn/20260724/d0780561f0114693b8968b904ef7f8c6/c.html)。

粗略比较：电耗20kWh/100km、充电综合单价1.3元/kWh时，约0.26元/km；燃油工况7.5L/100km、油价按9元/L作预算参数时，约0.675元/km。两者都是测算假设，不是你的车型实测和当天成交价。汽油标号、油价、车重和实际油耗变化都会改结果。

## 车宿：住哪里、什么时候改住酒店

**2022款SL03的车宿设置还需要匹配当前车机版本。** 厂家负责人的早期说明确认SL03有露营模式和不同能量管理模式，但本次未获得覆盖你当前OTA版本、明确写出露营时增程器禁用与低电量退出规则的完整官方说明，不能据此声称整夜一定不启动发动机，也不把网上15%或20%的说法直接当作你这台车的安全阈值。[厂家负责人原始说明](https://www.xchuxing.com/ins/132228)

在深蓝App或车机电子说明书里搜索“露营模式”“增程器”“低电量”，核对：露营模式是否禁用增程器、低电量或计时结束后的行为、车门是否需要手动锁定。若需要客服核实，可直接问：“2022款SL03增程版，当前车机版本为____，人在车内开空调过夜，露营模式下增程器是否可能自动启动，电量不足时如何处理？”

SL03的车床先在家试：前排调整到合适位置，按说明放倒后排，实量可躺长度与最窄宽度，处理靠背与行李厢之间的台阶、缝隙后再买床垫；不要套SUV床垫尺寸。后备厢装载时保留车内开门和离车通道。首次试住记录睡前/起床电量、室外温度、空调设置、睡眠时长，用自己的数据决定以后过夜前需要多少电。

在确认自己车型的正式睡眠模式、发动机禁用条件、低电量行为之前，不把“开空调睡一整晚”当作已验证方案。不要在地下车库、封闭棚内、尾气容易聚集的位置车宿；不要依靠留一道窗缝解决发动机尾气风险。车内不烧炭、不用燃气炉。可配一氧化碳报警器作额外防护，但不能因此允许发动机运行时睡觉。

优先顺序：允许过夜、有人管理的正规营地或地面停车场→核实夜间厕所与车辆出入的县城停车场→必要时酒店。高速服务区适合旅途中休息，噪声大，停车还应遵守管理要求；不为了找免费厕所专门上高速，也不占快充车位睡一整夜。

以下是**找点区域和搜索词，不是已经确认允许车宿的地点**：

| 地区 | 搜索/落脚方向 | 当地额外检查 |
|---|---|---|
| 永州、全州、兴安 | “县城 地面停车场 公厕 24小时” | 厕所是否夜间关闭，车位是否临货运干道 |
| 桂林 | 市区外围有人值守的地面停车场 | 不睡漓江滩地、桥下低洼地和地下车库 |
| 阳朔/兴坪 | 县城外围、正规营地、民宿院内协商车位 | 景区停车是否清场，夜里是否封门，是否允许车内留人 |
| 柳州/南宁 | 城市外围生活区附近的管理停车场 | 避开夜市、货运口、早市，不把公园门口等同于可过夜 |
| 北海/防城港/东兴 | 城区内陆侧正规地面停车场 | 风、潮位、海浪；不睡沙滩和海堤外；大风天住店 |
| 明仕/德天 | 大新县城；硕龙镇经核实的正规场地 | 景区闭园后是否清场，不在边境道路路肩停车睡觉 |
| 靖西 | 城区正规停车场或酒店 | 湖边草地、田埂、河边并非车宿停车场 |
| 巴马/东兰/河池/宜州 | 县城有厕所和管理人员的停车场 | 山体落石、低洼积水、夜间货车噪声 |

到场后问管理人员：今晚是否允许人在车内过夜？次日早上离场一共多少钱？厕所夜里开吗？是否锁门？得到允许后再落脚。下午16点开始找，最好17点前决定；不要天黑才进陌生山路找地方。

每4—6晚安排一次酒店，参考120—200元/晚，具体日期查实时房价，优先免费停车、热水、可洗烘衣物、步行能吃饭的。推荐住店城市是永州、阳朔或柳州、南宁、崇左或靖西、返程柳州；连续阴雨、被褥潮湿、睡眠不足时增加酒店，不硬撑。

看到暴雨、大风、山洪或地质灾害预警，按预警范围停止相应路段/户外安排；过夜点不要选河滩、桥下、山崖脚和海边防浪设施外侧。遇到低温而剩余电量不足以支撑已验证的整晚睡眠模式，补电或住店。

## 一个人的预算明细

| 项目 | 高速30天 | 国省道42天 |
|---|---:|---:|
| 餐饮，约40—60元/天 | 1200—1800 | 1680—2520 |
| 酒店，高速5晚/国道7晚，每晚120—200元 | 600—1000 | 840—1400 |
| 油电，含一定车宿空调消耗 | 1800—2800 | 1300—2300 |
| 通行费估算 | 1100—1600 | 不走高速且避开其他收费路时接近0 |
| 停车/少量营地 | 300—700 | 400—900 |
| 门票和少量项目 | 300—600 | 300—600 |
| 洗衣及日常杂项 | 200—400 | 300—500 |
| 合计取整 | 约5500—8900 | 约4800—8300 |

高速预算假设长距离转场较多用油、游玩时充电；国道假设更多行驶里程用公共充电。车型油耗未知，因此能源项只能做区间。若多数里程都烧油，应上调预算。预算压力大时，先缩短环线或减少付费项目，别把安全住店费用全部削掉。

每天只移动很短距离时，可按餐饮40—60元+停车0—20元+油电及偶尔住店分摊来记账。每天离开前记下“吃、油、电、停车、住宿、门票”六笔，走一周后用真实日均替代估算。

## 可删减与可增加的支线

- **想少花一点、只走约两周：** 长沙→永州→桂林→阳朔→柳州→桂林→长沙，先适应车宿和一个人长途生活。
- **想保留广西山水精华但少跑一点：** 删除东兴及部分海岸停留；南宁后直接去崇左、明仕、德天、靖西。
- **不喜欢巴马的慢生活：** 百色、河池只保留转场休息，删掉1—2个停留日。
- **想看侗寨/梯田：** 桂林—龙胜—三江另加3—5天，增加里程并看山路天气；收割后的梯田不按金黄稻田期待。
- **想去涠洲岛：** 另加2—3天及单独预算；核对官方船班、停航和留车安排后再订住宿。

实际更适合你的弹性做法：长沙进广西和回湘可用高速，桂林—阳朔、明仕—德天—靖西这些景观段走普通公路；天气差、身体累时再用高速缩短转场。以上A/B两版仍各自可执行，不要求混用。

## 出发前与每天的简单清单

出发前：胎压/轮胎、补胎工具、保险与救援、身份证/驾照、手机车钥匙及实体备用、充电账号、离线地图、车床试睡。装备先带平整床垫、保暖被、遮光帘、头灯、充电宝、饮水、垃圾袋和基本药品，不急着买成套露营装备。正式出发前在长沙附近的正规场地试一晚，确认门锁、睡眠模式、空调和电耗。

每天上午：看县级天气和预警→确认今天开到哪里→保存充电/加油备选→上午游玩或转场。

每天中午：吃饭兼补能→困了休息，不靠咖啡硬顶。

每天下午：少量游玩→16点起确认停车与夜间厕所→17点前确定车宿还是酒店→补足已验证的夜间用电。

天气查询入口：[湖南天气](https://hunan.weather.com.cn/index.shtml)、[广西天气](https://gx.weather.com.cn/indexOnline.shtml)、[桂林7天](https://www.weather.com.cn/weather/101300501.shtml)、[阳朔7天](https://www.weather.com.cn/weather/101300510.shtml)、[北海7天](https://www.weather.com.cn/weather/101301301.shtml)。出发前看发布时间，选择所在县而不是只看地级市。

路线不是每天必须完成的任务。好天气给山水，雨天给城市，累了原地休息；每走一周再决定下一周。
