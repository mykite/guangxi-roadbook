# 广西自驾逐日行程：高速30天 / 不走高速42天

整理日期：2026年11月5日。适用：一人，暂按2022款深蓝SL03增程版，纯电实际续航约160公里，车宿为主、定期住酒店。两版是二选一，不是连续走72天。

## 使用方法与日期

- 出发日未定，用D1、D2顺序执行。若2026年11月6日出发，高速版D30为12月5日，国道版D42为12月17日。后续雨天增加停留，所有日期顺延。
- 每天时间是安排建议，不是景区开放承诺。上午大致09:00—12:00，午饭及休息12:00—14:00，下午14:00—16:00；16:00起落实停车和补能，17:00前确定当晚住宿。长转场日提前到08:30出发。
- “驾驶”是当天计划驾驶区间，景区绕行和市内行驶已尽量留余量，但没有接入实时地图算路；不含吃饭、游览、充电和堵车。出发前按实际落脚点重新导航。
- 车宿栏写的是候选区域，不是已核实允许过夜的停车场。当天确认允许人在车内过夜、厕所夜间开放、总收费和车辆进出时间；没有合适场地就住酒店。充电栏是找桩城市，不是实时可用枪位承诺。
- 增程车露营规则取决于当前车机版本。先核对车内睡眠/露营模式是否禁用增程器，以及电量不足和计时结束后的行为；不能把“电量足”当成发动机整夜不启动的保证。地下车库、封闭棚内、尾气聚集处不车宿。详见原攻略车型说明。
- 不必每天多次补电：补能与吃饭、散步合并；长途可用符合手册的混动/保电策略。夜间所需电量用试住实测倒推，不承诺固定百分比够睡整夜。景区前保留足够燃油，不依赖睡觉时发动机发电。

## 当前天气与闭馆日

11月5日查到的近期信息显示，广西上旬阴雨、冷空气频繁，8—9日前后有降温降雨，北部湾海上风力增大。若11月6日前后出发，高速版D3—D4、国道版D3—D4需重点复查预警；雨势大就原地增加一天，不用后面的赶路把时间追回来。更远日期没有可靠的逐日天气承诺，每晚查下一站县级24—72小时预报。

桂林博物馆在临桂新区，不在东西巷旁；参观要单独留转场时间。桂林、柳州、合浦的相关博物馆通常周一闭馆，南宁的馆也需查当日通知。遇周一，把同城户外日和博物馆日调换；大雨与周一重合时就洗衣、休整，别安排另一个同样闭馆的馆。

## A：高速优先30天，每天单独安排

酒店基准安排D1、D7、D13、D19、D25，共5晚，每晚预算120—200元，不是已查到的实时房价。其他夜晚以获准车宿为计划；天气、疲劳或车辆供电不合适时增加酒店。主要转场走高速，景观段走正常开放的普通道路。

### D1 长沙→永州零陵：先把旅行节奏稳下来
- 驾驶：约320—370公里，4—5.5小时。
- 上午：08:30出发，衡阳方向途中休息20—30分钟，午饭不赶时间。
- 下午：抵达零陵，办理酒店入住；16:00左右轻走零陵古城、柳子街一带，晚上吃普通小店。
- 补能/夜宿：永州城区充电，按需要加油；住零陵区带停车位酒店，整理车床、洗澡，首日不另找车宿点。
- 雨天调整：取消古城长走，只采购、充电和休息；路上雨雾大可提前停衡阳，整表顺延一天。

### D2 永州→桂林：转场后只逛老城
- 驾驶：约210—260公里，3—4小时。
- 上午：09:00出发，经全州、兴安方向去桂林；途中只休息，不塞灵渠游览。
- 下午：午后抵达，车停正规场地，步行东西巷、靖江王城外围，晚饭后早点休息。
- 补能/夜宿：桂林七星区或叠彩区生活便利的地面管理停车场候选；城区充电，不把东西巷日间停车位当作车宿许可。
- 雨天调整：道路正常就完成转场，抵达后休息；有交通预警则留永州。

### D3 桂林：湖边慢走或博物馆日
- 驾驶：约10—60公里，0.5—2小时，取决于是否前往临桂。
- 上午：天气适合时走榕湖、杉湖开放步道，约2小时，不必买游船票。
- 下午：东西巷附近吃午饭，回车午休；有兴趣再逛一段漓江城区开放步道。
- 补能/夜宿：继续住已确认允许过夜的桂林停车点，午饭时补电，尽量不用每天搬车宿基地。
- 雨天调整：改为临桂桂林博物馆，09:30—12:00参观，下午休整；周一闭馆则洗衣、采购，户外等下一天。

### D4 桂林→兴坪：漓江风景只看一段
- 驾驶：约70—100公里，1.5—2.5小时。
- 上午：09:00前后出发，导航兴坪古镇正规停车场，按开放公路行驶，不跟随所谓沿江捷径。
- 下午：午饭后逛古镇和开放岸边，挑一段看黄布倒影方向风景；不爬老寨山、不安排徒步穿越。
- 补能/夜宿：离开桂林前补电，兴坪镇找经核实允许过夜的管理停车场或民宿院内；无合适场地就住镇上。
- 雨天调整：中到大雨、山路预警时不转进兴坪，留桂林，D4及后续顺延。

### D5 兴坪→阳朔：半天看江，半天安顿
- 驾驶：约30—50公里，1—1.5小时。
- 上午：09:00—11:00在兴坪开放岸边散步；水上项目如要体验，先核实营业、水位和限制，只选一个。
- 下午：午饭后去阳朔县城，先确定停车基地和充电；傍晚轻逛西街，天黑后步行或公共交通返回已定基地。
- 补能/夜宿：阳朔县城外围管理停车场候选，避开西街酒吧夜间噪声区。
- 雨天调整：上午直接休息，中午视路况去阳朔；不坐筏、不走江滩。

### D6 阳朔：遇龙河上游慢游
- 驾驶：约20—50公里，1—2小时。
- 上午：09:00到旧县附近正规停车点；选择旧县、遇龙桥方向的一段开放步道，走2—3公里即可。
- 下午：天气好可租自行车走一小段田园路，或喝茶发呆；不要求一天骑完整条遇龙河。
- 补能/夜宿：下午回阳朔城区补电，仍住同一获准车宿点；洗衣烘干可在城区解决。
- 雨天调整：取消骑行与河边长走，改为采购、洗衣和休息，留一整天空白也可以。

### D7 阳朔→柳州：到城里洗澡睡一晚
- 驾驶：约170—220公里，2.5—3.5小时。
- 上午：09:00出发去柳州，中途休息一次；不额外绕去荔浦收费景区。
- 下午：先入住酒店、洗澡洗衣；傍晚在柳江开放岸边走走，晚饭吃螺蛳粉或卷粉。
- 补能/夜宿：住柳州带停车位酒店，优先柳南区或鱼峰区交通方便的生活片区；下午充电。
- 雨天调整：只完成转场和酒店休整，取消夜景。

### D8 柳州：公园和老城
- 驾驶：约15—35公里，0.5—1.5小时。
- 上午：09:00—12:00龙潭公园轻松走，不追每个拍照点。
- 下午：午休后逛柳侯公园，傍晚再选窑埠或柳江岸边一处，避免来回穿城。
- 补能/夜宿：柳州生活区附近地面管理停车场候选；补给后找安静位置，避开夜市与货运口。
- 雨天调整：改柳州博物馆，馆方通常周一闭馆；闭馆就把公园日与返程柳州参观项目互换。

### D9 柳州→南宁：城市转场，不加青秀山
- 驾驶：约240—290公里，3—4小时。
- 上午：08:30—09:00出发，途中休息、吃饭，别边开车边赶午饭。
- 下午：抵达南宁后充电、采购；傍晚逛三街两巷或民生路片区，二选一即可。
- 补能/夜宿：南宁江南区或青秀区生活方便、获准过夜的地面停车点；先确定夜宿再进老城。
- 雨天调整：抵达后直接休息，不在雨中走老城。

### D10 南宁：看民族文化，给身体放一天假
- 驾驶：约20—50公里，1—2小时。
- 上午：09:30—12:00广西民族博物馆，先查馆方当日开放和入馆要求。
- 下午：午饭、午休、洗衣；雨停后任选一段邕江开放步道，不再加第二个大景点。
- 补能/夜宿：沿用南宁获准车宿基地，午饭或洗衣期间充电。
- 雨天调整：保留开馆的室内参观；遇闭馆则把D10改纯休整日，不开车找另一个同样闭馆的馆。

### D11 南宁→北海：到海边先安顿
- 驾驶：约210—260公里，3—4小时。
- 上午：09:00出发，午前后到北海，午饭吃普通小店，不急着买海鲜。
- 下午：先找城区停车基地、充电，16:00左右去银滩开放区域看海一小时。
- 补能/夜宿：海城区或银海区内陆侧管理停车场候选；不在沙滩、堤外和迎风海边过夜。
- 雨天调整：取消银滩，城区采购与休息；大风天气直接住店。

### D12 北海：银滩和侨港，慢一点
- 驾驶：约15—35公里，0.5—1.5小时。
- 上午：09:00—11:00银滩开放区域散步，遵守海滩旗示与现场管理，不把下水列为任务。
- 下午：午休后逛侨港街区，吃一两样小吃；风小、无预警时再看海，16:30左右返城。
- 补能/夜宿：继续住北海同一获准停车基地，按实测夜耗决定是否补电。
- 雨天调整：城区短逛或休息；不追日落，不在风浪里守海边。

### D13 北海：老街、洗衣、住酒店
- 驾驶：约10—30公里，0.5—1小时。
- 上午：09:00—11:00北海老街，沿主街慢走，午饭问清价格和份量。
- 下午：入住酒店，洗澡、洗衣烘干、整理潮湿被褥；不给这半天再加行程。
- 补能/夜宿：北海酒店，预算120—200元，停车条件先核实；城区补电。
- 雨天调整：缩短老街，把大部分时间给酒店休整。

### D14 北海→钦州→防城港：分段看海岸城市
- 驾驶：约200—250公里，3—4.5小时。
- 上午：08:30—09:00出发去钦州，午饭并休息、补能。
- 下午：去防城港，先定落脚点；天气合适时在西湾开放步道散步，不再绕远去别的海滩。
- 补能/夜宿：钦州或防城港城区充电；防城港内陆侧管理停车场候选。
- 雨天调整：可只走到钦州，当天过夜，防城港次日顺延。

### D15 防城港→东兴：口岸城市慢逛
- 驾驶：约60—100公里，1.5—2.5小时。
- 上午：09:00出发，午前到东兴，先解决停车、午饭。
- 下午：步行口岸城市开放街区和老街，不安排出境，不闯临时管制区域。
- 补能/夜宿：东兴城区充电与获准车宿，避开口岸货车通道。
- 雨天调整：减少步行，在城区休息；不要改走更偏僻的沿边路躲雨。

### D16 东兴→崇左：转入边关田园路线
- 驾驶：约210—280公里，3—4.5小时。
- 上午：08:30出发，按实时导航选择上思方向的高速组合，途中休息一次。
- 下午：抵达崇左后补给、充电；傍晚太平古城开放街区轻走1小时即可。
- 补能/夜宿：崇左江州区生活片区管理停车场候选，优先方便第二天出城的位置。
- 雨天调整：转场后直接休息，取消古城夜逛；道路预警则留东兴。

### D17 崇左→大新补能→明仕田园：把时间给田园
- 驾驶：视是否绕大新补电，约120—190公里，2.5—4小时。
- 上午：09:00出发；先核对明仕、硕龙补能情况，必要时经大新县城充电、午饭，不赌景区桩。
- 下午：明仕田园开放区域步行2—3公里，看峰林、村落；竹筏自选，不买整套项目。
- 补能/夜宿：明仕经核实允许过夜的民宿院内或管理场地候选；找不到就住当地民宿，不夜间折返赶路。
- 雨天调整：留崇左或大新县城，等雨势缓解再进田园，整表顺延。

### D18 明仕→德天→硕龙：只安排瀑布一个主项目
- 驾驶：约60—100公里，1.5—3小时。
- 上午：08:30前后出发到德天游客集散中心，按景区接驳进入，留3—4小时看瀑布。
- 下午：午饭后视体力继续景区步行，14:30—15:30离开，去硕龙镇安顿；不再加峡谷。
- 补能/夜宿：白天核实硕龙可用桩；无补电条件且夜间电量不够，就住店，不用睡觉时发动机补电兜底。
- 雨天调整：只有景区正常开放、无相关预警才游览；强降雨或关闭则留镇上，德天顺延。

### D19 硕龙→靖西→鹅泉：小景点配酒店
- 驾驶：约100—150公里，2.5—4小时。
- 上午：09:00出发去靖西，先在城区吃饭、充电，不绕进未经核实的沿边小路。
- 下午：天气合适时去鹅泉，留1.5—2小时；随后回靖西酒店洗澡休息。
- 补能/夜宿：靖西城区酒店，优先停车、洗衣方便的生活区；城区补能。
- 雨天调整：取消鹅泉，直接酒店休整，次日与旧州合并或顺延。

### D20 靖西→旧州→靖西：留一天给村镇
- 驾驶：约30—60公里，1—2小时。
- 上午：09:00出发去旧州，在正规停车场停车，步行老街、看绣球手工，停留2小时。
- 下午：当地午饭，天气好再走一小段田园；15:00前后回靖西，不叠加漂流。
- 补能/夜宿：靖西同一生活片区找获准车宿场地，下午按夜耗补电。
- 雨天调整：旧州只短逛或取消，留城区；不因闲着而临时钻峡谷。

### D21 靖西→渠洋湖→靖西：湖景日
- 驾驶：约60—100公里，1.5—3小时。
- 上午：09:00出发到渠洋湖正规游客服务/停车区域，沿开放岸线看景；游船先看风力、营业和价格。
- 下午：午饭后休息，14:00—15:00返回靖西，补充食品饮水，准备第二天转场。
- 补能/夜宿：靖西城区充电，继续获准车宿；不睡湖边草地和田埂。
- 雨天调整：取消湖区，城区休息；这是可与D19/D20调换的天气机动日。

### D22 靖西→百色：转场与城市参观
- 驾驶：约130—170公里，2—3小时。
- 上午：09:00出发，中午到百色，先吃饭和确定停车。
- 下午：百色起义纪念馆作为可选项目，先核实开放；不感兴趣就城区开放步道短走。
- 补能/夜宿：百色右江区管理停车场候选，城区充电、检查胎压和轮胎。
- 雨天调整：开馆时保留室内参观，闭馆就补给与休整。

### D23 百色→巴马：到县城安顿再说
- 驾驶：约120—170公里，2—3.5小时。
- 上午：09:00出发去巴马，中午在县城吃饭。
- 下午：先充电和找落脚点；天气合适再走县城开放滨水步道，不急着往村里跑。

## 日常费用与买票

基本预算沿用总攻略：高速30天约5500—8900元；国道42天约4800—8300元。酒店5晚/7晚已计入，因天气增加的住宿和延长天数另算，另留1500—2000元应急，不含买装备和车辆维修。

想按天记账，可分为：餐饮40—60元/天；车宿停车/营地按实际报价；酒店日加120—200元预算；门票仅在实际购买日记账；油、电、通行费按当天支付记录。这里不把未核实的票价、油耗和停车收费相加成虚假的精确每日总价。

德天是主推付费项目，其余如鹅泉、旧州、水上项目、青秀山和灵渠按兴趣购买，不提前把全程套票锁死。基本路线不含涠洲岛；上岛需另外安排船班、停车、住宿和天气机动日。

## 每晚只落实四件事

1. 下一站县级24—72小时天气、道路预警和当天开放信息。
2. 明天只开到哪个城市、途中在哪里午休，是否需要拆段。
3. 一个主要补能候选和一个备用点，夜间用电按实测留余量。
4. 今晚停车是否明确允许留人过夜、厕所是否夜间开放；不满足就住酒店。

天气入口：[湖南天气](https://hunan.weather.com.cn/index.shtml)、[广西天气](https://gx.weather.com.cn/indexOnline.shtml)。看预报发布时间和所在县，不能把网页边栏的旧文章当作当天预报。
